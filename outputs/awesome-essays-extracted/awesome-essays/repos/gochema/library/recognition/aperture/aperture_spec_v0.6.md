# Aperture Specification v0.6 — Post-Audit

## Status: The audit corrects our operator architecture. The decisive gain is the combination of apoha + anusandhāna + deha-bheda, with the newly foregrounded counter-evidence that anusandhāna does not cross bodies.

---

## The Division of Labour

The audit gives us four operations that now divide the work precisely:

| Operation | Function | Textual Basis | Status |
|-----------|----------|--------------|--------|
| **Apoha** (Eᵢ) | Content determination: Eᵢ: Aᵢ → xᵢ. Distinguishes this from that. | ĪPK 1.3.7 | [T] |
| **Anusandhāna** (Cᵢ) | Stream integration: Cᵢ(xₜ, xₜ₋₁) → one connected stream. Links this cognition with that cognition. | TĀ 16.242 | [T] |
| **Deha-bheda** (Bᵢ ≠ Bⱼ) | Integration boundary: where connective synthesis stops. Bᵢ ≠ Bⱼ ⇒ Cᵢ ⊅ Dⱼ. | TĀ 10:12113 | [T] |
| **Pratibimba** | Inter-stream influence: other streams affect the local field without entering its synthesis directly. Rⱼ→ᵢ ⊂ Dᵢ but Dⱼ ⊄ Dᵢ. | TĀ 10:12113; Ratié Vivṛti | [T] |

This is the strongest architecture yet. It is not "apoha is the aperture." It is: **apoha determines contents; anusandhāna unifies the stream; deha-bheda limits that unity to one body; pratibimba allows other streams to affect and expand the local field without entering its synthesis directly.**

## The Corrected Aperture Operator

Previous (v0.5):

```
Λᵢ = Closeᵢ ∘ E_worldᵢ ∘ E_contentᵢ ∘ Iᵢ
```

Corrected (v0.6):

```
Λᵢ = Max_Bᵢ[Cᵢ ∘ Eᵢ ∘ Iᵢ ∘ Jᵢ]
```

Where:
- Jᵢ: manifestation
- Iᵢ: alternative generation
- Eᵢ: determinate exclusion (apoha)
- Cᵢ: connective synthesis (anusandhāna)
- Max_Bᵢ: maximal closure permitted by embodiment (deha-bheda)

This yields:

```
Oᵢ* = Closure_Bᵢ(Jᵢ, Mᵢ, Iᵢ, Vᵢ, Eᵢ, Cᵢ)
```

The inexternal hypothesis remains:

```
Dᵢ ≡_inext Oᵢ*
```

## What TĀ 16.242 Actually Changes

The verse:

```
bhogyajñānaṃ nānyadeheṣv anusandhānam arhati
```

"Knowledge experienced in one body cannot perform connective synthesis with other bodies."

**Previously**, our unresolved edge was: "Why is one closed process one private field?"

**Now**, the text gives a candidate answer: **one field is the maximal domain over which connective synthesis can operate.**

Define:

```
Cᵢ = {x | x can enter reciprocal anusandhāna within Bᵢ}
```

Then a candidate phenomenal domain is:

```
Dᵢ = MaximalConnectedDomain(Cᵢ)
```

This is stronger than treating the body merely as a container. The body becomes the CONDITION under which cognitions can be: retained together, recognized together, compared, attributed to one stream, integrated across time.

---

## What This Does NOT Prove

The verse gives an operational exclusion rule: cross-body cognition cannot enter one connective synthesis.

It does NOT prove:

```
maximal connective synthesis = phenomenal unity
```

A functionalist could accept the entire architecture and say: "This explains memory integration, ownership, report, and behavioural unity — but nothing about experience."

The final bridge remains:

```
MaxAnusandhānaDomain(Bᵢ) ⟷? Dᵢ
```

That is now the sharpest form of the frontier.

## The Universalization Argument Becomes More Constrained

TĀ 16.242 pressures any argument moving directly from cognitive unity to one universal subject.

If connective synthesis is body-limited, then "one knower connecting cognitions" may establish only:

```
Sᵢ = one knower within one embodied stream
```

It does NOT establish:

```
Sᵢ = Sⱼ = S∞
```

The universal Śaiva conclusion therefore needs a separate argument:

```
Ground(Sᵢ) = Ground(Sⱼ) = C∞
```

This is compatible with:

```
Sᵢ ≠ Sⱼ
```

That sharply separates:

- **Token unity:** Dᵢ ≠ Dⱼ
- **Ground unity:** Ground(Dᵢ) = Ground(Dⱼ)

## The Three Frameworks Now Separate Cleanly

| Framework | Claim | Status |
|-----------|-------|--------|
| **Process inexternalism** | Dᵢ ≡_inext Oᵢ*. Each body-indexed maximal synthesis is intrinsically one phenomenal token. No universal conscious ground required. | [H] — compatible with texts but not required by them |
| **Participatory inexternalism** | Dᵢ ≡_inext Oᵢ* AND Dᵢ = πᵢ(M₀). Distinct tokens locally actualize a common manifest ground. | [H] — compatible, adds participation structure |
| **Pratyabhijñā** | Oᵢ* = Contractionᵢ(C∞). Each local field is a body-conditioned contraction of one universal consciousness. | [T] — the texts assert this, but it is a metaphysical claim |

The text now gives STRONGER evidence for local token distinction than we previously recognized, while preserving ultimate nondivision.

## The Cleanest Logical Sequence

1. **Manifestation:** Jᵢ(x) = x appears.
2. **Determination:** Eᵢ(A) = x. Apoha determines this content rather than alternatives.
3. **Retention:** Mᵢ(xₜ₋₁) = xₜ₋₁ remains available.
4. **Connection:** Cᵢ(xₜ₋₁, xₜ) = one temporally extended stream.
5. **Embodied limit:** Cᵢ cannot synthesize contents across Bᵢ/Bⱼ.
6. **Local subject:** Sᵢ = MaximalDomain(Cᵢ).
7. **Universal ground:** Pratyabhijñā adds Ground(Sᵢ) = C∞.

The first six stages are increasingly compatible with a naturalized process account. The seventh is the distinctive metaphysical universalization.

The audit confirms that Utpaladeva and Abhinavagupta possessed not merely a list of relevant properties, but a near-complete operator architecture:

| Operation | Sanskrit Term | Function |
|-----------|-------------|----------|
| Manifestation | jñāna/prakāśa | appearing |
| Retention | smṛti | past remains available |
| Determination | apohana | this rather than that |
| Temporal connection | anusandhāna | stream unity across time |
| Alternative generation | vikalpa/imagination | novel forms |
| Value weighting | rāga | what matters |
| Finite possibility space | kañcukas | what is possible |
| Cross-stream closure | deha-bheda | where synthesis stops |
| Inter-stream manifestation | pratibimba | other fields affect mine |

That is an astonishingly sophisticated functional anatomy of subjectivity.

## The New Exact Frontier

The frontier should now be written as:

```
Why is the maximal body-bounded domain of manifestation,
retention, determination, and connective synthesis
intrinsically one phenomenal field?
```

Or formally:

```
MaxAnusandhāna_Bᵢ(Oᵢ) ⟷? Dᵢ
```

This is better than the previous expression:

```
Apt(Oᵢ) ⟷? Dᵢ
```

because **anusandhāna now gives the aperture a specific internal unity condition.**

The remaining unexplained implication is no longer vague:

```
functional connective unity ⇏ phenomenal co-presence
```

unless we add either:
- Dᵢ ≡_inext Oᵢ* (process inexternalism)
- Dᵢ = πᵢ(C∞) (participatory inexternalism)
- or another psychophysical principle
