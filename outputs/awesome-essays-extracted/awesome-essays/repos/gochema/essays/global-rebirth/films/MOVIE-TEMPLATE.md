# MOVIE-TEMPLATE — how every rebirth film gets built (canon)

> Instance per film: `films/<NN-name>/MOVIE.md`. Film 11 (Śaiva) already
> ran this recipe with separate STRUCTURE/STORYBOARD/ESSAY files.

## Beat skeleton (16–26 min per film)
| Act | Beats | What |
|---|---|---|
| I — THE SCENE | B1 cold-open (30–60s filmed scene + one owner-tone line) · B2 two-layers (the theory compressed) | motif stated as image, not sentence |
| II — THE MECHANISM | B3-B5 (three process moves or six-field sequence) | the reads: primary quotes in serif |
| III — THE MOMENT | B6 exact-moment-of-death (tradition's own definition) · B7 metaphysics (why-it-repeats) · B8 climax (the tradition's most radical line) | the payload |
| IV — THE RETURN | B9 guard (best objection, hard cuts) · B10 reprise/close (B1 rhymed, changed) · B11 series-next | motif returns carrying everything |

## Rhythm law (per film, adjust)
- Bell/gong/room-sound = act markers (max 4+1). Silence budget 10–15s.
- Cut density: exposition ≤4s · ONE fast section ≤2s (optional) ·
  ONE ≥20s take (the money shot) · guard = hard cuts only.
- Reads paced slow (130wpm), bridges 150. Never read-and-cut on one frame.

## CINEMATOGRAPHY (the "beautiful" layer — one look per film)
- **Light rule**: each tradition gets ONE light source type (its ritual
  light): flame / dawn / torch / window / ember / noon-marble / shaft-light
  in dust / mist / candle / indigo night / 70s tungsten / overexposed white.
- **Palette**: element-fluid body from VISUAL-GRAMMAR + tradition skin.
- **Camera**: tripod/locked-off default (ceremony); handheld only in the
  fast section; the money shot = one slow push or one locked long take.
- **Texture**: film-grain allowed only for channeled/modern stops; stone/
  water/metal surfaces carry the ancient ones. No stock faces.
- Frame composition: symmetry for sacred (Egyptian/Greek/Christian),
  asymmetry-with-void for the deletion films (Madhyamaka-line/Gnostic).

## File contents per MOVIE.md
1. Title + runtime + thesis-line (theory in the title, TITLES.md).
2. Beat table (B-numbers, timings, rhythm spec).
3. Cinematography block (light/palette/camera/texture — instance the canon).
4. READ list (quote IDs from resources/NN + WEAVE-GLOBAL — primary only).
5. Money-shot description + series-next line.
6. Flags: verify-at-draft cites, clearances.
