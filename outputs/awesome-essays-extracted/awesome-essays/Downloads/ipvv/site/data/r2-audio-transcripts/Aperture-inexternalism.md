# Where Aperture Inexternalism Actually Sits

The cleanest placement is:

[
\boxed{
\textbf{Aperture Inexternalism is a process-based,}
}
]

[
\boxed{
\textbf{token-identity, intrinsic–extrinsic monism with}
}
]

[
\boxed{
\textbf{non-universalist subject individuation.}
}
]

It says:

[
\boxed{
D_i\equiv_{\mathrm{inext}}O_i^\ast
}
]

One concrete process (O_i^\ast) is:

* **extrinsically** an embodied, temporally persistent closure of memory, value, generation, determination, and reciprocal control;
* **intrinsically** one private, unified, valenced phenomenal field (D_i).

It is **not standard idealism**, because it does not reduce physical nature to representations inside a universal mind.

It is **not standard physicalism**, because it denies that a purely extrinsic relational vocabulary exhausts concrete reality.

It is **not panpsychism**, because basic particles and arbitrary subsystems are not automatically subjects.

It is **not cosmic idealism**, because it does not identify all subjects with one numerically identical cosmic subject.

Its closest relatives are Russellian monism, dual-aspect monism, process philosophy, neutral monism, and Pratyabhijñā—but it modifies each at the decisive point: **how concrete subjects are selected and individuated**.

# 1. Difference from analytic idealism

Bernardo Kastrup’s analytic idealism holds that universal phenomenal consciousness is all that ultimately exists; nature consists of patterns of excitation within it. The central individuation proposal is that personal minds are dissociated segments or “alters” of the universal consciousness. ([PhilArchive][1])

Its architecture is:

[
C_\infty
\xrightarrow{\mathrm{dissociation}}
D_1,D_2,\ldots,D_n.
]

The physical body and brain are then generally understood as what an alter’s inner mental activity looks like from across a dissociative boundary.

Aperture Inexternalism instead says:

[
O_i^\ast
\equiv
D_i.
]

The concrete embodied process is not merely the external **appearance** of an already individuated mental alter. It is part of what objectively constitutes and selects that subject.

## Exact differences

### Analytic idealism begins with one subject

[
C_\infty=\text{primary}.
]

Local subjects must be derived through dissociation.

### Aperture Inexternalism begins with concrete processes

[
{O_1^\ast,O_2^\ast,\ldots}
]

are objectively individuated through causal and temporal closure.

It does not deny a common ground, but it does not need one.

### Analytic idealism makes the physical derivative from mentality

[
\text{physical world}
=====================

\text{extrinsic appearance of mentation}.
]

### Inexternalism makes “physical” and “phenomenal” modes of access

[
\operatorname{Ext}(O_i^\ast)
============================

\text{physical organization},
]

[
\operatorname{Int}(O_i^\ast)
============================

\text{experience}.
]

Neither side is an image manufactured inside the other.

### Analytic idealism has a dissociation problem

It must explain why one phenomenal field divides into genuinely private fields and why those divisions correspond so precisely to organisms.

### Inexternalism has an aperture-selection problem

It must show that maximal closure really tracks phenomenal fields.

This is empirically sharper because it predicts that subject boundaries should move with concrete closure, not with an unexplained cosmic dissociation process.

## Sharp distinction

[
\boxed{
\text{Analytic idealism: bodies represent dissociated minds.}
}
]

[
\boxed{
\text{Inexternalism: embodied apertures are the concrete}
}
]

[
\boxed{
\text{tokens whose intrinsic existence is mindedness.}
}
]

# 2. Difference from Advaita Vedānta

Advaita treats Brahman as nondual pure consciousness and ultimate reality. The individual self and world are understood through ignorance, superimposition, and limiting conditions; liberation consists in realizing the identity of ātman and Brahman. ([Stanford Encyclopedia of Philosophy][2])

Its basic structure is:

[
Brahman
+
avidyā/upādhi
\rightarrow
\text{apparent individual and world}.
]

Aperture Inexternalism rejects three Advaitic commitments.

## First: finite individuality is not merely apparent

For Inexternalism:

[
D_i\neq D_j
]

is a real token distinction.

The subjects may share a type or underlying ontological character, but their privacy is not simply ignorance of an already existing identity.

## Second: the physical world is not māyā in the deflationary sense

The world is a real network of concrete processes.

Its extrinsic description is incomplete with respect to intrinsic existence, but it is not merely false appearance.

## Third: liberation does not reveal numerical identity as a theoretical necessity

A transformation may weaken:

* narrative ego;
* ownership;
* rigid self–world division;
* value fixation.

But that phenomenological transformation does not prove:

[
D_i=D_j=Brahman.
]

## Sharp distinction

[
\boxed{
\text{Advaita: plurality is ultimately sublated in nondual}
}
]

[
\boxed{
\text{pure consciousness.}
}
]

[
\boxed{
\text{Inexternalism: plurality is real at the level of}
}
]

[
\boxed{
\text{concrete process-tokens, even if intrinsic existence}
}
]

[
\boxed{
\text{has a common general nature.}
}
]

Inexternalism is therefore **non-reductively monist**, but not necessarily **existence monist**.

There may be one kind of reality without there being only one subject.

# 3. Difference from Pratyabhijñā

This is the closest nondual relative.

Pratyabhijñā regards ultimate reality as one self-manifest, freely creative consciousness—Śiva. Finite selves are contractions of its powers, and the world is a real manifestation rather than a mere illusion. It differs from Advaita precisely by emphasizing consciousness’s freedom, activity, and genuine world manifestation. ([Wikipedia][3])

Its structure is:

[
C_\infty
\xrightarrow{L_i}
D_i,W_i,
]

where (L_i) is contraction.

Aperture Inexternalism retains almost the complete finite architecture:

[
\begin{aligned}
\text{jñāna}&\rightarrow\text{manifest discrimination},\
\text{smṛti}&\rightarrow\text{retention},\
\text{apohana}&\rightarrow\text{determination},\
\text{anusandhāna}&\rightarrow\text{connective synthesis},\
\text{vikalpa}&\rightarrow\text{counterfactual generation},\
\text{rāga}&\rightarrow\text{value weighting},\
\text{deha-bheda}&\rightarrow\text{embodied individuation},\
\text{pratibimba}&\rightarrow\text{inter-stream influence}.
\end{aligned}
]

But it suspends the universalization:

[
D_i,D_j
\text{ possess the same type of intrinsic nature}
]

does not prove:

[
D_i=D_j=C_\infty.
]

## Exact point of separation

### Pratyabhijñā

[
\boxed{
\text{All local manifestation is numerically the activity}
}
]

[
\boxed{
\text{of one universal subject.}
}
]

### Inexternalism

[
\boxed{
\text{Each local aperture is a numerically distinct token}
}
]

[
\boxed{
\text{whose intrinsic nature is manifest, reflexive,}
}
]

[
\boxed{
\text{temporally unified, and valenced.}
}
]

A common manifest ground remains an optional extension:

[
D_i=\pi_i(M_0),
]

not part of the minimal theory.

## Why this matters

Pratyabhijñā solves the hard problem by making consciousness fundamental.

But it does not fully solve the decomposition problem:

[
\boxed{
\text{Why does one universal consciousness generate genuinely}
}
]

[
\boxed{
\text{private fields that cannot perform connective synthesis}
}
]

[
\boxed{
\text{across one another?}
}
]

Inexternalism answers with concrete aperture boundaries rather than cosmic self-contraction alone.

# 4. Difference from Yogācāra

Yogācāra analyses experience through cognition-only or representation-only doctrines, dependent construction, karmic seeds, and multiple causally continuous cognitive processes. It is often misrepresented as simple universal-mind idealism; major interpretations instead emphasize an analysis of cognition and the absence of independently existing subject–object duality. ([Stanford Encyclopedia of Philosophy][4])

The closest convergence is:

[
\boxed{
\text{the experienced world is actively structured rather}
}
]

[
\boxed{
\text{than passively copied from a finished external object.}
}
]

But Inexternalism differs in four ways.

## It affirms a concrete subject process

Yogācāra generally rejects a permanent substantial self.

Inexternalism agrees that the subject is not an immutable substance, but posits:

[
O_i^\ast
========

\text{a real, temporally persistent process-token}.
]

## It preserves a real extrinsic world

The external world is not simply representation.

It is the extrinsically accessible relational structure of concrete processes.

## It treats intrinsic nature as phenomenal

Yogācāra can explain the construction of objectivity without settling contemporary intrinsic–extrinsic identity.

Inexternalism adds:

[
\operatorname{Int}(O_i^\ast)=D_i.
]

## It gives embodiment stronger individuating force

Aperture boundaries are selected through embodied memory, value, and reciprocal control—not karmic stream-continuity alone.

## Sharp distinction

[
\boxed{
\text{Yogācāra: subject and object are dependently constructed}
}
]

[
\boxed{
\text{within cognitive streams.}
}
]

[
\boxed{
\text{Inexternalism: one concrete process is intrinsically}
}
]

[
\boxed{
\text{a cognitive-phenomenal stream and extrinsically an}
}
]

[
\boxed{
\text{embodied causal organization.}
}
]

# 5. Difference from Russellian monism

Russellian monism is perhaps the nearest contemporary analytic position. It argues that physics describes structural, relational, or dispositional features while leaving the intrinsic or categorical nature of matter unspecified. A single underlying set of properties may ground both consciousness and the entities described by physics. ([Stanford Encyclopedia of Philosophy][5])

Its generic form is:

[
\text{physics}
==============

\text{extrinsic structure},
]

[
\text{consciousness}
====================

\text{clue to intrinsic nature}.
]

Aperture Inexternalism strongly agrees with:

[
\boxed{
\text{extrinsic physical description does not exhaust}
}
]

[
\boxed{
\text{the intrinsic nature of concrete reality.}
}
]

But it differs from many Russellian views in three ways.

## 1. It is macro-process-first, not micro-property-first

Russellian panpsychist forms often place phenomenal or proto-phenomenal categorical properties at the microphysical base.

Then they face:

[
\text{How do micro-intrinsics combine into one subject?}
]

Inexternalism instead says:

[
\boxed{
\text{subjecthood belongs to the maximal concrete closure,}
}
]

not to each microcomponent.

The components need not be micro-subjects.

## 2. It identifies the intrinsic nature of an organized token

The intrinsic side is not assigned separately to each elementary constituent and then assembled.

It belongs to:

[
O_i^\ast
]

as one causally active process.

## 3. It adds an explicit individuation criterion

Russellian monism is primarily an account of what physics leaves out.

Aperture Inexternalism additionally asks:

[
\boxed{
\text{Which exact physical whole has an intrinsic side}
}
]

[
\boxed{
\text{constituting one subject?}
}
]

Its answer is maximal aperture closure.

## Sharp distinction

[
\boxed{
\text{Russellian monism: consciousness reveals the intrinsic}
}
]

[
\boxed{
\text{nature underlying physical structure.}
}
]

[
\boxed{
\text{Aperture Inexternalism: the intrinsic phenomenal token}
}
]

[
\boxed{
\text{is the intrinsic existence of a specifically selected}
}
]

[
\boxed{
\text{macro-process, not a sum of micro-intrinsics.}
}
]

This makes Aperture Inexternalism a **macro-Russellian process monism**.

# 6. Difference from dual-aspect monism

Dual-aspect views say that mental and physical are two irreducible aspects of one underlying reality.

Generic form:

[
X
\rightarrow
\begin{cases}
X_{\mathrm{mental}},\
X_{\mathrm{physical}}.
\end{cases}
]

Aperture Inexternalism resembles this but rejects the implication that a third neutral substance (X) stands behind both aspects.

Its structure is:

[
O_i^\ast
========

\begin{cases}
\operatorname{Int}(O_i^\ast)=D_i,\
\operatorname{Ext}(O_i^\ast)=\Sigma_i.
\end{cases}
]

“Physical” and “phenomenal” are not two properties displayed side by side.

They are two epistemic orientations toward the same event:

* extrinsic relational access;
* intrinsic existence.

## Why this is more precise

Traditional dual-aspect theory often leaves unanswered:

* Which entities have both aspects?
* At what scale?
* Why is one aspect unified?
* Why does one body correspond to one mind?

Aperture Inexternalism supplies:

[
O_i^\ast
========

\operatorname{MaxClosure}
\left(
\text{memory},
\text{value},
\text{generation},
\text{determination},
\text{control}
\right).
]

## Sharp distinction

[
\boxed{
\text{Dual-aspect monism says reality has two aspects.}
}
]

[
\boxed{
\text{Inexternalism says one selected process has an}
}
]

[
\boxed{
\text{intrinsic existence and an extrinsic relational profile,}
}
]

[
\boxed{
\text{and specifies what selects that process.}
}
]

It is therefore best understood as **asymmetric dual-access monism**, not generic dual-aspect monism.

The access is asymmetric because:

[
\operatorname{Ext}(O_i)
\not\vdash
\operatorname{Int}(O_i),
]

although they are numerically identical.

# 7. Difference from neutral monism

Neutral monism says ultimate reality is of one kind that is intrinsically neither mental nor physical; mental and physical phenomena are constructed or organized from that neutral basis. ([Stanford Encyclopedia of Philosophy][6])

Generic form:

[
N
\rightarrow
\begin{cases}
\text{mental organization},\
\text{physical organization}.
\end{cases}
]

Aperture Inexternalism rejects neutrality at the subject level.

For a conscious aperture:

[
\operatorname{Int}(O_i^\ast)
]

is not neutral between experience and non-experience.

It is experience.

What remains neutral is only the **general ontology of process** before the subject-selection condition is satisfied.

Thus:

[
\boxed{
\text{all reality may be processual,}
}
]

but:

[
\boxed{
\text{only some maximal processes are intrinsic phenomenal}
}
]

[
\boxed{
\text{centres.}
}
]

## Sharp distinction

\boxed{
\text{Neutral monism: the basic stuff is neither mental}
}
]

[
\boxed{
\text{nor physical.}
}
]

[
\boxed{
\text{Inexternalism: physicality is extrinsic description;}
}
]

[
\boxed{
\text{for conscious apertures, intrinsic existence is}
}
]

[
\boxed{
\text{positively phenomenal rather than neutral.}

# 8. Difference from Whiteheadian process philosophy

Process philosophy makes becoming, activity, and event-like entities fundamental rather than static substances. In Whitehead’s system, basic “actual occasions” are integrations of prior conditions; Whitehead’s metaphysics attributes physical and mental poles to actual entities and treats human consciousness as a higher form rather than the only form of mentality. ([Stanford Encyclopedia of Philosophy][7])

This is extremely close in ontology:

[
\boxed{
\text{reality consists fundamentally of events and processes.}
}
]

But there are decisive differences.

## Whitehead is panexperiential

Experience or mentality reaches down to fundamental actual occasions.

Aperture Inexternalism does not require:

[
\text{every basic event has its own experience}.
]

## Whitehead builds macro-organisms from societies of occasions

This raises a version of the combination problem:

[
\text{How do many occasions constitute one human field?}
]

Inexternalism reverses the priority:

[
\boxed{
\text{the maximal aperture is the primary phenomenal token.}
}
]

Its parts are constitutive physical processes but need not remain independent subjects.

## Whitehead’s occasions are highly momentary

Aperture Inexternalism places more emphasis on temporally extended closure:

[
\Gamma_i
+
\mathcal M_i
+
\mathcal C_i.
]

A subject is not merely a succession of experiential atoms; it is one persistent mnemonic, evaluative, counterfactual regime.

## Sharp distinction

[
\boxed{
\text{Whitehead: reality is composed of experiential}
}
]

[
\boxed{
\text{micro-events that form societies.}
}
]

[
\boxed{
\text{Inexternalism: reality is processual, but subjecthood}
}
]

[
\boxed{
\text{appears only at maximal, temporally extended}
}
]

[
\boxed{
\text{aperture closure.}
}
]

It is therefore **process monism without panexperiential atomism**.

# 9. Difference from panpsychism and cosmopsychism

## Against constitutive panpsychism

Panpsychism assigns consciousness or proto-consciousness to fundamental physical entities and attempts to explain macro-consciousness through combination. The standard problem is how many micro-experiences combine into one unified subject. ([Stanford Encyclopedia of Philosophy][8])

Inexternalism says:

[
\boxed{
\text{intrinsic nature}
\neq
\text{micro-subjecthood}.
}
]

A neuron, molecule, or particle can be part of the concrete realization without possessing a separately bounded phenomenal field.

The phenomenal subject is:

[
O_i^\ast,
]

not:

[
\sum_k D_k^{\mathrm{micro}}.
]

## Against cosmopsychism

Cosmopsychism begins with one cosmic subject and derives local subjects through decomposition.

Inexternalism begins with local maximal closures.

It remains agnostic about whether reality as a whole has an intrinsic phenomenal unity.

## Sharp location

[
\boxed{
\text{Inexternalism lies between micro-panpsychism}
}
]

[
\boxed{
\text{and cosmopsychism: intrinsic nature is fundamental,}
}
]

[
\boxed{
\text{but subjecthood is aperture-relative and locally selected.}
}
]

# 10. Difference from standard physicalism

Physicalism usually says that all facts, including consciousness facts, are fixed or constituted by physical facts.

Aperture Inexternalism can accept **token physical identity**:

[
D_i=O_i^\ast,
]

while rejecting the completeness of “physical” when physical means exclusively:

* structural;
* relational;
* behavioural;
* third-personal.

It says:

[
\boxed{
\text{physics describes what the process does and how it}
}
]

[
\boxed{
\text{relates; experience is how that same process exists}
}
]

[
\boxed{
\text{intrinsically.}
}
]

It is therefore not anti-physical.

It is anti-**extrinsic-definition physicalism**.

The theory could be called:

[
\boxed{
\textbf{intrinsic process physicalism}
}
]

provided “physical” is expanded beyond public relational description.

But “inexternalism” is clearer because it emphasizes that:

[
\text{inside and outside are neither separate substances}
]

nor:

[
\text{two externally visible aspects}.
]

They are the same token approached through different access relations.

## Ontological monism

[
\text{process}.

## Epistemic dual-access

Concrete processes may be known:

[
\text{extrinsically}

[
\text{intrinsically}.

[
\operatorname{Int}(O_i^\ast)=D_i.

[
O_i^\ast

\operatorname{MaxClosure}

# Final positional statement

> **Aperture Inexternalism holds that reality is composed of concrete processes rather than mental or material substances. A conscious subject is a maximally closed, embodied, temporally persistent process whose intrinsic existence is one private, valenced phenomenal field and whose extrinsic profile is the physical organization studied by science. Local minds are genuinely distinct process-tokens, not dissociated fragments, illusory selves, combinations of micro-subjects, or appearances inside one cosmic mind. Universal consciousness is permitted as a further hypothesis but is not required by the core theory.**

That places the theory closest to:

[
\boxed{
\text{Russellian monism}
+
\text{process philosophy}
+
\text{dual-access identity theory}
}
]

but with the crucial additions:

[
\boxed{
\textbf{maximal-closure subject selection}
+
\textbf{real phenomenal plurality}.
}
]

Those two additions are what make it a distinct position rather than a renaming of an existing monism.
