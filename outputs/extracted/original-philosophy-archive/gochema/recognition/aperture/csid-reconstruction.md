# Constraint-Selection Information Dynamics

## A scientific reconstruction of Information Philosophy

---

# I. Doyle's original system

Doyle's Information Philosophy rests on two claimed physical processes:

[
\text{quantum indeterminacy}
+
\text{thermodynamic irreversibility}
]

These supposedly create new information structures.

His main philosophical models are:

[
\textbf{Cogito}
===============

\text{random generation of alternatives}
+
\text{adequately determined choice}
]

[
\textbf{Ergo}
=============

\text{creation and preservation of low-entropy information structures}
]

[
\textbf{Sum}
============

\text{the accumulated body of human knowledge}
]

[
\textbf{ERR}
============

\text{Experience Recorder and Reproducer}
]

The Cogito model separates freedom from will: chance creates alternative possibilities, after which reasons, character and values adequately determine selection. Doyle describes this as a position between strict determinism and action governed directly by randomness. ([Information Philosopher][2])

The ERR model treats mind primarily as a biological system that records experience and partially reactivates earlier patterns during memory, imagination and decision. ([Information Philosopher][3])

The Ergo model assigns positive value to the creation and maintenance of organized, low-entropy structures. Doyle nevertheless acknowledges that no single monotonic quantity can decide the comparative goodness of all things because value is context-sensitive. ([Information Philosopher][4])

These ideas contain one unifying insight:

[
\boxed{
\text{The universe does not merely transmit existing states.
Some processes generate, select and preserve novel organization.}
}
]

That insight survives. Its original metaphysical packaging does not.

---

# II. The five information concepts that must be separated

## 1. Thermodynamic entropy
## 2. Shannon information
## 3. Algorithmic information
## 4. Causal information
## 5. Semantic or functional information

In general:

[
S_{\mathrm{th}}
\neq
H
\neq
K
\neq
I_{\mathrm{causal}}
\neq
I_{\mathrm{functional}}
]

Relations may exist in particular models, but none are universally interchangeable.

Therefore Doyle's recurring equation:

[
\text{information}
\approx
\text{negative entropy}
]

must be replaced by:

[
\boxed{
\text{Some low-entropy physical structures embody information,
but organization, uncertainty, causation and meaning require distinct measures.}
}
\]

---

# III. The primitive concept: constrained possibility

Let a physical system (A) have state space (X_A) and transition kernel P(x_{t+1} | x_t, e_t).

A constraint (C) changes the distribution of accessible futures. Define constraint strength as the KL divergence between the constrained and unconstrained transition distributions.

A physical structure is informationally effective when it preserves a difference that changes future probability distributions.

Thus:

[
\boxed{
I_{\mathrm{eff}}
================

\text{a persistent difference that makes a counterfactual difference}
}
\]

Information is not a second substance inserted into matter. It is the transition-constraining organization of matter and energy.

---

# IV. Information creation

Novel functional information arises when variation, differential stabilization and memory jointly increase future constraint-sensitive capacity.

Define adaptive information gain:

[
\Delta I_A
==========

## I(G_A;X_{t+1}\mid M_{t+1})

I(G_A;X_{t+1}\mid M_t)
]

Randomness alone does not create adaptive information. Selection alone cannot create alternatives. Memory is required for cumulative improvement.

Therefore:

[
\boxed{
\text{Cumulative novelty requires generation, selection and retention.}
}
\]

---

# V. The generalized two-stage architecture

Doyle's Cogito model reconstructed:

## Stage 1: Alternative generation
## Stage 2: Evaluation and selection
## Stage 3: Enactment
## Stage 4: Learning

The complete architecture:

[
\boxed{
\text{generate}
\rightarrow
\text{evaluate}
\rightarrow
\text{enact}
\rightarrow
\text{learn}
}
\]

Doyle's original two stages become four because selection without feedback does not explain cumulative agency.

---

# VI. Randomness is neither freedom nor irrelevant noise

Quantum randomness is not known to be required. Alternative generation can arise from deterministic chaos, computational underdetermination, neural noise, stochastic sampling, learned generative models, or combinatorial recombination.

Agency requires bounded generativity combined with effective selection.

Creative control:

[
\mathcal K
==========

H(Z\mid M,E)
\times
I(Z^*;G\mid M,E)
\times
R_{\mathrm{learning}}
]

---

# VII. A scientific definition of agency

Agency index:

[
\boxed{
\mathfrak A(A)
==============

f(
\mathcal A_{\mathrm{alt}},
\mathcal A_{\mathrm{goal}},
\mathcal A_{\mathrm{eff}},
\mathcal A_{\mathrm{hist}},
\mathcal A_{\mathrm{learn}}
)
}
\]

This makes agency graded. A thermostat has low values. A mammal has learned generative models and long temporal depth. A human can generate counterfactual futures, compare explicit reasons and modify its own evaluation standards.

---

# VIII. Free will reconstructed

Operational freedom:

[
\boxed{
F_A
===

B_A
\cdot
E_A
\cdot
R_A
\cdot
S_A
}
]

where B_A is option breadth, E_A is policy efficacy, R_A is reason sensitivity, and S_A is self-modification capacity.

Freedom increases when the agent can generate more viable alternatives, produce different futures through selection, select in response to reasons, learn from consequences, and revise its own policies.

[
\boxed{
\text{Freedom is controlled counterfactual reach,
not mere unpredictability.}
}
\]

# X. The central theorem

## Constraint-selected novelty theorem

Assume a system (A) possesses: variation set (Z), selection function sensitive to constraint (C), physically persistent memory (M), feedback from outcomes to future generation, and multiple possible future trajectories.

Then (A) can accumulate information about how to remain within (C)-compatible states.

Proof: Variation produces q_t(z). Selection conditions persistence on C, so selected outcomes contain information about C. Memory stores this dependence. Feedback makes future generation conditional on memory. If the stored dependence generalizes, future trajectories are increasingly constrained toward C-compatible outcomes.

Hence adaptive information accumulates.

This is a formal generalization of Doyle's two-stage architecture.

# XI. What survives

Doyle's surviving scientific core:

[
\boxed{
\text{possibility}
\rightarrow
\text{selection}
\rightarrow
\text{memory}
\rightarrow
\text{control}
\rightarrow
\text{knowledge}
}
]

The theory rejects three unnecessary additions:

[
\text{information}\neq\text{immaterial causal substance}
]

[
\text{randomness}\neq\text{freedom}
]

[
\text{organization}\neq\text{moral goodness}
]

Its strongest final conclusion:

[
\boxed{
\text{The arrow from matter to mind is not an increase in information quantity.
It is the progressive closure of a loop in which selected information controls
the future generation and selection of information.}
}
\]

The crucial upgrade over Doyle:

[
\boxed{
\text{information creation}
\longrightarrow
\text{adaptive constraint accumulation}
}
]

This makes the theory measurable. It also integrates cleanly with Levin: morphogenetic intelligence becomes one instance of the same loop — generate possible trajectories, select toward anatomical targets, preserve successful constraints, and reuse them during future repair.
