## Part 2: Complexity Science — Why the Aperture May Exist at a Macro-Scale

Complexity science's first contribution is the possibility that the causally relevant individual is not found at the microscopic scale.

### 2.1 Causal Emergence (Hoel)

Hoel's causal-emergence framework measures whether a macro-level model can carry more effective information about interventions and outcomes than a micro-level description. In model systems, causal effectiveness can peak at a macro-scale because coarse-graining removes degeneracy and noise. (PubMed Central PMC3856819)

This does not mean the macro violates microphysics. It means:

```
the most informative causal unit may be a higher-level
organization rather than an individual component.
```

**Formal definition:**

```
CE(Oᵢ, s) = causal effectiveness of process Oᵢ at scale s
```

Then search for:

```
sᵢ* = argmax_s CE(Oᵢ, s)
```

This gives a candidate scale of individuality.

**Pratyabhijñā correspondence:**
The cell, neuron, organ, and organism may all perform local discrimination. But anusandhāna requires a scale at which cognitions become parts of one continuous trajectory. Causal emergence gives a possible scientific interpretation:

```
one subject-scale may be the macro-scale at which temporal
information becomes maximally synergistic and interventionally
coherent.
```

### 2.2 Integrated Information Decomposition (ΦID)

Integrated Information Decomposition extends this idea by distinguishing redundant, unique, and synergistic information. Researchers have used it to identify information available only to a collective process and have reported reductions in relevant synergistic organization during anaesthesia and disorders of consciousness. (PubMed 34804593)

This gives a potential scientific counterpart to:

```
Cᵢ = connective synthesis (anusandhāna).
```

**The decisive limitation:**

```
synergistic information ≠ phenomenal co-presence
```

A social group, flock, or computer network may possess collective information unavailable to individual parts without obviously becoming one conscious subject.

Recent multi-agent active-inference simulations even show that a flock-level boundary and collective information can emerge from local interactions. The flock encodes information not available to each bird individually. That demonstrates emergent joint agency — not automatically a new phenomenal subject. (arXiv 2511.10835)

**Scientific lesson:** Causal emergence can identify a **candidate bearer**:

```
BearerCandidate(Oᵢ) = macro-process with privileged causal organization
```

It cannot establish:

```
BearerCandidate(Oᵢ) ⇒ Phenomenal(Oᵢ)
```

### 2.3 What Causal Emergence Contributes

- Privileged macro-scales
- Synergistic information
- Objective alternatives to micro-reduction
- Possible measures of system unity

### 2.4 What Causal Emergence Cannot Contribute

- Phenomenal unity from causal unity
- A unique consciousness measure
- The step from integrated information to experience

## Part 3: Levin — The Body as a Scalable Cognitive Boundary

Michael Levin provides the closest scientific analogue to the body as a regime of determination.

### 3.1 The Cognitive Light Cone

Levin's "cognitive light cone" defines an agent by the spatial and temporal scale of the goals it can sense, model, and attempt to affect. He explicitly describes a self as bounded by the range of events it can measure and regulate, rather than simply by skin or anatomy. (PubMed 31920779)

This closely matches our reconstructed body:

```
Bᵢ = ⟨Sᵢ, Aᵢ, Vᵢ, Γᵢ, Cᵢ⟩
```

The body is a process that determines:
- which deviations count as errors
- which future states are pursued
- what falls within regulatory concern
- which components coordinate
- what spatial and temporal scale matters

### 3.2 Bioelectric Networks

Levin's developmental bioelectricity work proposes that electrical coupling through ion channels and gap junctions scales cell-level homeostatic competencies into tissue- and organism-level goal pursuit. Bioelectric patterns can encode target morphologies, coordinate regeneration, and recruit cells into larger problem-solving networks. (PubMed 35401131)

**Cell-level regime:** Each cell has local: sense → compare → act → reassess.

**Tissue-level regime:** Gap-junction coupling allows many cells to share regulatory states:

```
{c₁, ..., cₙ} →[K] O_tissue
```

**Organism-level regime:** The collective pursues anatomical or behavioural outcomes unavailable to isolated parts:

```
GoalScale(O_organism) > GoalScale(cₖ)
```

This is arguably the best existing scientific model for:

```
how many local powers become one larger regime of memory,
value, and action.
```

### 3.3 Levin and Anusandhāna

In our model, anusandhāna is not merely memory retrieval. It is the connective operation through which temporally distinct cognitions belong to one ongoing subject.

A Levin-style interpretation would be:

```
Cᵢ = the network process through which local states are made
      available to one system-level goal trajectory.
```

A gap-junction-coupled tissue can possess pattern memories and coordinated target states that individual cells do not possess independently. Levin describes morphogenetic systems as navigating anatomical state spaces and correcting perturbations relative to stored target morphologies. (PubMed 37204591)

This gives scientific content to:

```
smṛti + anusandhāna
```

The system retains a target, compares current conditions with it, and recruits different local actions into one temporally extended correction process.

### 3.4 What Levin Does Not Establish

Levin's work supports graded agency, collective cognition, and body-scale memory. It does not demonstrate that all goal-directed biological collectives are conscious.

The crucial gap:

```
collective competency ⇏ collective phenomenality
```

A regenerating tissue may exhibit: memory, error correction, flexible problem-solving, system-level decisions, causal autonomy. Whether it feels anything remains unknown.

### 3.5 The Most Important Levin Prediction for Our Framework

The candidate phenomenal boundary should track changes in **effective cognitive coupling**, not fixed anatomy.

If coupling expands:

```
Kᵢ↑ ⇒ GoalScale(Oᵢ)↑
```

If coupling fragments:

```
Kᵢ↓ ⇒ Oᵢ → {Oᵢ₁, Oᵢ₂, ...}
```

This gives a direct experimental analogue of:

```
deha-bheda ↔ contraction
```

and:

```
pratibimba/coupling ↔ expansion
```

But "expansion" here means expansion of system-level agency. Phenomenal expansion remains a further claim.

### 3.6 What Levin Contributes

- Multiscale agency
- Body as cognitive regime
- Bioelectric integration
- Goal-scale expansion
- Pattern memory
- Graded individuality

### 3.7 What Levin Cannot Contribute

- Proof of sentience
- Proof that tissues have phenomenal fields
- Universal conscious ground

## Part 4: Semantic Information — The Scientific Counterpart to Rāga

Shannon information measures correlation. It does not distinguish a signal that matters to an organism from one that does not.

### 4.1 Kolchinsky and Wolpert's Semantic Information

Kolchinsky and Wolpert define semantic information as information about an environment that is causally necessary for a system to maintain its own existence. They test causal necessity by intervening to scramble correlations and measuring the effect on viability. (arXiv 1806.08053)

This gives a rigorous form to intrinsic significance.

Let I(X;Y) be statistical information between system X and environment Y. Let V(Xₜ) measure continued viability. Then information is semantically significant where destroying the relevant correlation reduces viability:

```
ΔV = V_intact − V_scrambled > 0
```

### 4.2 Correspondence with Rāga

Rāga should not be reduced to conscious wanting. At the lowest level it can be reconstructed as:

```
the asymmetry between states that sustain the process and
states from which the process tends to move away.
```

Thus:

```
Vᵢ(a) = expected contribution of a to continued viability
         or preferred organization
```

This weights exclusion:

```
Eᵢ(Aᵢ | Vᵢ) = a*
```

The system does not merely distinguish alternatives. It distinguishes them according to what matters for its persistence.

This is the cleanest scientific analogue of:

```
rāga → directed world disclosure
```

### 4.3 The Safer Hierarchy

Semantic information is not felt valence. A bacterium can contain viability-relevant information. That does not establish semantic value = felt pleasure or pain.

The safer hierarchy is:

| Level | Term | Definition |
|-------|------|------------|
| 1 | Semᵢ | Objective significance for persistence |
| 2 | Vᵢ | Endogenous regulatory weighting |
| 3 | νᵢ | Felt positive or negative valence |

The unresolved bridge:

```
(Semᵢ, Vᵢ) ⟷? νᵢ
```

This is where affective neuroscience and the rasa/self-affection analysis become relevant later.

## Part 5: Active Inference — A Formal Model of World-Carving

Active inference models an agent as maintaining itself within a restricted range of states by updating beliefs and acting to minimize expected free energy.

Its importance here is not the slogan "the brain minimizes surprise." It is the architecture: generative model + prediction + precision + action + self-maintenance.

### 5.1 Mapping to the Five Aperture Operations

**Manifestation:** Incoming states are inferred as causes:

```
Jᵢ: sₜ → q(zₜ)
```

**Memory:** Past states constrain present inference:

```
q(zₜ | zₜ₋₁)
```

**Imagination:** The generative model produces counterfactual futures:

```
Iᵢ: zₜ → {ẑₜ₊₁^π}
```

**Value:** Prior preferences weight expected states:

```
Vᵢ: ẑ → P_preferred(ẑ)
```

**Exclusion:** Posterior inference and policy selection suppress incompatible alternatives:

```
Eᵢ: {zₖ, πₖ} → (z*, π*)
```

This is the strongest existing formal analogue of:

```
imagination + rāga + apohana
```

### 5.2 Markov Blankets and Deha-Bheda

A Markov blanket statistically separates internal states from external states through sensory and active states. This has been used to model biological and neural boundaries at multiple scales. (arXiv 2006.02741)

**Critical correction:** A naïve mapping would be: Markov blanket = subject boundary. That is wrong.

Markov blankets can be defined at many scales: cell, organ, brain region, organism, group. Their existence does not select one privileged conscious subject. Technical critics have also shown that different Markov-blanket formulations are not equivalent and that some free-energy derivations require stronger assumptions than are often stated. (arXiv 2001.06408)

The correct role:

```
Markov blankets generate candidate system partitions,
NOT phenomenal subjects.
```

### 5.3 The Active Inference Contribution to Aperture Theory

Active inference formalizes:

```
Wᵢ = the world as inferentially and practically available
      to one self-maintaining process
```

It gives:

```
Eᵢ^world = precision-weighted selection of relevant distinctions
```

It does not explain why that enacted world is manifest.

### 5.4 What Active Inference Contributes

- Generative world models
- Counterfactuals
- Value-weighted selection
- Action-perception loops
- Candidate boundaries

### 5.5 What Active Inference Cannot Contribute

- Unique subject selection
- Phenomenal identity
- Proof that Markov blankets feel

## Part 6: CIMC — The Closest Explicit Consciousness Architecture

The CIMC whitepaper proposes that a system is conscious when it implements **self-organized second-order perception that increases global coherence**. (CIMC 2024)

### 6.1 The Three Claims

This combines three claims:
1. The system forms perceptions (P⁽¹⁾ = world-directed perception)
2. The system perceives or models its own perceptual processes (P⁽²⁾ = perception of P⁽¹⁾ and internal processes)
3. This second-order organization improves coherence across the whole system (ΔCoh(Oᵢ | P⁽²⁾) > 0)

CIMC is important because it attempts to **build the subject** rather than merely correlate brain activity with reports.

### 6.2 Mapping CIMC to the Aperture

- Manifestation-like discrimination: P⁽¹⁾ ⟷ Jᵢ
- Reflexive organization: P⁽²⁾ ⟷ computational analogue of vimarśa
- Connective synthesis: GlobalCoherence ⟷ Cᵢ
- Development: SelfOrganization ⟷ Γᵢ
- Exclusion: Coherent global model suppresses incompatible interpretations and policies

### 6.3 Where CIMC Is Strongest

CIMC can operationalize a **critical emergence event**. We might observe a transition where a system begins to:
- Preserve a persistent self-model
- Integrate previously independent processes
- Detect and repair incoherence
- Generate counterfactuals about its own cognition
- Revise its own goals
- Distinguish self-caused from externally caused changes

That would be a strong candidate for the emergence of Oᵢ*.

### 6.4 Where CIMC Overreaches

Second-order perception can still be described functionally. A system could: represent its own representations, improve global coherence, report introspective states, correct itself — without the theory demonstrating why any of this is manifest.

Thus:

```
P⁽²⁾ + Cohᵢ ⇏ Mᵢ
```

Nor should computational metacognition be equated directly with vimarśa. Timalsina's interpretation concerns the pre-reflective act through which consciousness is already manifest to itself, not necessarily an explicit internal model of a first-order process.

The best relation is:

```
P⁽²⁾ = a testable computational candidate for an architecture
       associated with explicit reflexivity

not:

```
P⁽²⁾ = vimarśa

### 6.5 Strongest CIMC–Inexternalist Hypothesis

perception closes previously independent processes into one

Then:

```
Oᵢ* = CriticalClosure(P⁽¹⁾, P⁽²⁾, Mᵢ, Vᵢ, Eᵢ)
```

Inexternalism adds:

```
Dᵢ ≡_inext Oᵢ*
```

The latter remains the metaphysical wager.

### 6.6 What CIMC Could Genuinely Test

CIMC cannot directly test whether a system feels. It can test whether the proposed aperture architecture is coherent and whether its components emerge together.

Construct systems varying independently in: Γ, Sem, CE, K, C, I, E, P⁽²⁾.

Then test for phase transitions in:
- Persistent self-maintenance

- Endogenous goal revision
- Novel counterfactual generation

**System A:** Externally imposed goals, modular episodic inference, no persistent self-maintenance, no endogenous valuation, no developmental continuity.

**System B:** Persistent self-organized trajectory, endogenous significance, coherent system-level memory, internal counterfactual generation, second-order perception, capacity to revise itself.

Then compare whether consciousness-relevant judgements track behavioural competence or Oᵢ*.

This cannot reveal experience directly, but it can discriminate superficial behavioural theories from aperture theories.

## Part 7: Wolfram — Observer-Relative Quotienting

Wolfram contributes a different part of the framework.

### 7.1 Observer Theory

Wolfram's observer theory emphasizes that observers are computationally bounded and persistent in time. Because they cannot track all underlying computational detail, they compress or coarse-grain irreducibly complex processes into stable macroscopic regularities. (Wolfram 2023)

This gives a natural formal analogue of finite perspective.

Let the underlying process contain states Ω = {ω₁, ω₂, ...}. A bounded observer cannot distinguish every state. It imposes an equivalence relation:

```
ωₐ ∼ᵢ ωᵦ
```

whenever the difference is inaccessible or irrelevant to observer i.

The observer's world is then:

```
Wᵢ = Ω / ∼ᵢ
```

This is almost exactly a quotient form of world-carving.

### 7.2 Apoha Correspondence

Apoha determines by exclusion: x = this rather than excluded alternatives. Wolframian observer quotienting identifies a class by treating many microstates as equivalent:

```
[x]ᵢ = {ω : ω ∼ᵢ x}
```

The combination is:

```
finite cognition constructs determinate objects by collapsing
computationally inaccessible differences and excluding
incompatible equivalence classes.
```

This gives a powerful scientific-formal bridge:

```
apohana ↔ observer-specific quotienting
```

It is not historical equivalence. It is structural correspondence.

### 7.3 The Ruliad and Participatory Inexternalism

Wolfram describes the ruliad as the entangled limit of all possible computations, with observers accessing particular slices according to computational boundedness and persistence. (Wolfram 2021)

This resembles:

```
Wᵢ = πᵢ(M₀)
```

But the resemblance must be controlled.

**Wolfram:** R = all computational possibilities. Wᵢ = observer-accessible slice of R.

**Pratyabhijñā:** C∞ = universal self-manifest consciousness. Dᵢ = contracted manifestation of C∞.

The crucial difference:

```
R ⇏ manifest consciousness
```

The ruliad is a computational-metaphysical structure. It does not by itself possess prakāśa, vimarśa, or experience.

### 7.4 Wolfram's Real Contribution

Wolfram helps formalize:
- Why finite observers encounter stable laws
- Why each observer accesses only a quotient
- How persistence and computational boundedness generate effective worlds
- Why no bounded observer can exhaust the underlying process

He does not explain:
- Why a quotient is experienced
- Why one observer corresponds to one phenomenal field
- Why a computationally bounded process is self-affective
- What makes one observer boundary intrinsic rather than selected by an analyst

Thus Qᵢ (observer quotient) belongs inside the aperture model:

```
Oᵢ* = ⟨..., Qᵢ, ...⟩
```

It does not replace the inexternal identity.

### 7.5 What Wolfram Contributes

- Observer-relative quotienting
- Computational boundedness
- Persistence
- Irreducible generation
- Possibility-space metaphysics

### 7.6 What Wolfram Cannot Contribute

- Manifestness
- Self-affection
- Intrinsic subject boundaries
- Evidence that the ruliad is consciousness

## Part 8: Levin's Platonic Space and Wolfram's Ruliad

Levin's developing Platonic-space proposal treats anatomical, physiological, and behavioural patterns as locations or structures within a nonphysical possibility space that physical systems can discover or instantiate. Levin explicitly presents this as an exploratory research programme, not a settled empirical result. (Levin, Forms of Life, Forms of Mind)

### 8.1 The Three Models

**Levin:** P = structured possibility space of forms and policies. Organisms navigate or instantiate patterns in P.

**Wolfram:** R = space of all computationally realizable processes. Observers access bounded slices of R.

**Pratyabhijñā:** C∞ = unrestricted power of manifestation. Finite subjects actualize contracted possibilities.

### 8.2 The Shared Structure

These models share:

```
actual physical histories occupy a restricted region of a much
larger structured possibility domain.
```

But they differ on the nature of the domain:

| Model | Domain | Content |
|-------|--------|---------|
| Levin | P | Forms, policies, cognitive patterns |
| Wolfram | R | Computational possibilities |
| Pratyabhijñā | C∞ | Powers of self-manifest consciousness |

### 8.3 The Neutral Notation

Inexternalism should not identify these spaces. It can use a neutral master notation:

```
Ω = space of dynamically realizable forms, policies, and
    distinctions
```

Then Oᵢ* selects and enacts one trajectory through Ω:

```
Γᵢ: t ↦ ωᵢ(t)
```

The phenomenal question is whether Γᵢ is intrinsically lived time (τᵢ), or merely correlated with it.

## Part 9: Computational Irreducibility and Svātantrya

Wolfram's computational irreducibility says that the outcome of many processes cannot be obtained through a general shortcut; the process must effectively be run. (Wolfram 2026)

### 9.1 What This Does and Does Not Give

This does not give metaphysical freedom. But it changes how finite agency should be interpreted.

An organism's future need not be:
- Externally precomputable
- Reducible to a compact closed-form description
- Already represented by the organism
- Predictable by another bounded observer

Thus:

```
law-governed ⇏ practically predetermined for bounded observers
```

Imagination may generate genuinely novel configurations in the sense that they emerge only through running the process:

```
Iᵢ(t) → a_new
```

where no shorter prediction was available.

### 9.2 The Clean Distinction

This gives a naturalistic analogue of limited svātantrya:

```
endogenous, irreducible generation within constraints
```

It does not establish absolute independence from causal conditions.

The clean distinction is:

| Type | Definition |
|------|------------|
| Absolute svātantrya | Uncaused self-determination |
| Operational autonomy | Internally organized counterfactual generation |
| Computational irreducibility | Absence of general predictive shortcuts |

These may coexist, but none entails the others.

## Part 13: The Hardest Edge — Co-Presence

Even this refined architecture does not derive phenomenal unity. A system may be causally integrated, semantically autonomous, self-modelling, globally coherent, computationally irreducible, and temporally continuous — without it logically following that x,y ∈ Dᵢ are experienced together.

This is the **co-presence gap**:

```
FunctionalIntegration(x,y) ⇏ CoPresent(x,y)
```

Every scientific theory must choose one of three responses:

### Identity Response

```
FunctionalIntegration = CoPresence
```

**Problems:** Why would this identity be true? It does not follow from any physical description.

### Law Response

```
FunctionalIntegration ⇒ CoPresence
```

by a psychophysical law.

**Problems:** This is a brute postulate. It explains nothing.

### Fundamental-Ground Response

Integrated processes delimit local actualizations of an already manifest ground.

```
Dᵢ = πᵢ(M₀)
```

**Problems:** Needs independent evidence for M₀.

Pratyabhijñā chooses the third. CIMC appears to choose a version of the first. Inexternalism treats the first as a token identity hypothesis while admitting it cannot be conceptually derived from an extrinsic description alone.

## Part 15: The Final Synthesis

The science now supports a powerful naturalized description:

```
A finite agent is a dynamically maintained macro-process that
preserves a trajectory, integrates subagents, assigns intrinsic
significance, generates possible futures, excludes alternatives,
and constructs an observer-relative world under embodied
constraints.
```

Pratyabhijñā adds:

```
This process does not merely compute manifestation; it is a
contracted act of self-manifest consciousness.
```

Process inexternalism proposes the intermediate position:

```
The finite process and the finite phenomenal field are one event,
intrinsically lived and extrinsically describable.
```

The exact frontier is therefore:

```
Does maximal closure across memory, value, counterfactual
generation, and determination select the physical token whose
intrinsic existence is one field of experience?
```

Or formally:

```
MaxClosure(Γᵢ, Semᵢ, CEᵢ, Mᵢ, Iᵢ, Vᵢ, Eᵢ, Cᵢ, P⁽²⁾) ⟷? Dᵢ
```

That is the unified problem.

The texts provide the functional anatomy. Levin provides multiscale embodiment and collective agency. Active inference provides generation, valuation, and exclusion. Causal emergence provides candidate macro-scale unity. Wolfram provides bounded observer quotienting and irreducible world construction. CIMC provides a buildable reflexive architecture.

None of them supplies the final entailment to manifestness.

That final gap is exactly where the three strongest interpretations remain in contention:

```
Functionalism:    the organization constitutes experience
Inexternalism:    the organization IS experience intrinsically
Pratyabhijñā:     the organization contracts universal experience
```

The research programme should now test everything **up to that fork** as aggressively as possible, without pretending the experiments have already settled which metaphysical interpretation is true.
