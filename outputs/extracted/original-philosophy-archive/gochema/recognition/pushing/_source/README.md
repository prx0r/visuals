## The corpus of PUSHING sessions

The 30+ `LOGICVID-session-*.md` files in `recognition/pushing-tantraloka/` + `recognition/pushing-ipvv/`
are the worked enquiries; the guide cites the method from these.

## What each file contributes to the method

- **logicvidsmethod.md** — the master method: the graph-tension → paradox → hidden-premises →
  branches → research → new-graph loop; the double-pass (construct/destroy) + provenance audit; the
  repeatable `inquiries/<id>/` artifact shape.
- **logicframework.md / logicframework2.md** — the 6-level explanatory frame
  (M→D→B→N→W→R) and the source-controlled reconstruction with a per-claim `Status` key.
- **logicdog.md** — a worked enquiry ("Is a dog Śiva?") showing the honesty rule (ontological vs
  explicit-liberating recognition; the "relabelling" accusation and the strongest reply).
- **logic5/6/7.md, logicvid3.md** — specific penetrations (the S-role, Branch C, the regress).
- **logicvid-postmortem.md** — the tooling lesson (forced alignment for the film; not the method).
