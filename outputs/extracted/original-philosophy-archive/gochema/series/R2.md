# R2 — bucket map + access

Creds live ONLY in `/root/.r2-env` (600). Never commit, never paste.
`tools/r2.sh` sources it at runtime.

```bash
bash tools/r2.sh ls renders/              # list essay render prefixes
bash tools/r2.sh ls renders/daimon-threshold/ --recursive
bash tools/r2.sh fetch renders/spanda/v1/source_essay.md ./  # fetch to cwd
```
