# Sanskritree V2 research-to-component map

| Resource family | Planned role | Gate before activation |
| --- | --- | --- |
| DCS, Heritage, Vidyut, Sanskrit Voyager | independent morphology/sandhi candidates | API/version/licence adapter test |
| MITRA, Mitrasamgraha, Itihasa, Saamayik | retrieval/alignment calibration | dataset-card licence and split leakage audit |
| Cologne lexica, WordNet, SARIT, GRETIL | lexical evidence and editions | provenance granularity and redistribution review |
| Sanskrit Library | SLP1 morphology candidates, XML review workflow, TEI conventions | configured transport; source/API and licence audit |
| Muktabodha, NGMCP, TextGrid | primary text/witness discovery | citation and access rights review |
| Pantograph, LeanDojo, ReProver | formal checking/retrieval | pinned Lean compatibility and no-`sorry` test |
| ProofBridge and robustness benchmarks | semantic-equivalence evaluation design | reproduce evaluation protocol, not paper claims alone |

The project stores source-level evidence rather than copying an external system’s interpretation. The first real corpus target remains one permission-cleared Manthanabhairavatantra unit; the included `mbt_kumarika_pilot.yaml` is a non-distributable test fixture, not an edition.
