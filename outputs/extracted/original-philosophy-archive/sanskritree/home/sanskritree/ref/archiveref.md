# Sanskritree — Archive.org Source Reference

> Archive.org is the gold mine for editions and manuscripts that never became proper e-texts, especially Navya-Nyāya and Śaiva tantra. But it is also full of duplicated scans, broken OCR, misleading filenames, and texts already available cleanly elsewhere.

**Rule:** Check GRETIL/SARIT/Muktabodha first → use Archive.org for printed editions → OCR only genuinely unavailable works or commentaries.

## 2. Archive.org collections worth downloading wholesale

### Kashmir Series of Texts and Studies
- **Search:** [Archive](https://archive.org/search?query=%22Kashmir+Series+of+Texts+and+Studies%22)
- **Content:** Central printed source for Trika/Kashmir Śaiva — Tantrāloka, Svacchandatantra, Netratantra, Mālinīvijayottara, Kṣemarāja, Utpaladeva, Abhinavagupta
- **Format:** Devanāgarī, includes untranslated Sanskrit commentaries

### Trivandrum Sanskrit Series (18.7 GB)
- **Collection:** [Archive](https://archive.org/details/Trivandrum_Sanskrit_Series_TSS)
- **Priority volumes:**
  - TSS 67/71: Tantrasamuccaya with Vimarśinī (temple ritual, mantra, Kerala tantra)
  - TSS 68: Tattvaprakāśa with Tātparyadīpikā (Śaiva Siddhānta ontology)
  - TSS 69: Īśānagurudevapaddhati (Śaiva ritual compendium)
  - TSS 70+: Āryamañjuśrīmūlakalpa (Buddhist ritual/tantric compendium)

### eGangotri manuscript collections
- **Search:** [Archive](https://archive.org/search?query=creator%3A%22eGangotri%22+Sanskrit)
- **Collection:** [Dharmartha Trust](https://archive.org/details/dharmarthtrustjkcollectionbyegangotri)
- **Content:** Photographed manuscripts from Raghunath Temple, including unpublished Nyāya, Vaiśeṣika, Tantra, ritual texts
- **Note:** Manuscript images, not reliable e-texts. Archive OCR is rough search aid only.

### Digital Library of India
- **Collection:** [DLI](https://archive.org/details/digitallibraryindia)
- **Sanskrit filter:** [Search](https://archive.org/search?query=collection%3Adigitallibraryindia+language%3ASanskrit)
- **Note:** Massive collection, bad metadata, many otherwise unavailable texts

## 5. OCR priority tiers

### Tier A — highest intellectual return
1. **Gadādharī Śabdakhaṇḍa** (manuscript) — Navya-Nyāya language theory, no clean IAST
2. **Tattvacintāmaṇi–Dīdhiti–Dīdhitiprakāśa** — complete layered commentary
3. **Pakṣadhara's Āloka with Darpaṇa** — central Mithila Navya-Nyāya
4. **Rucidatta's Prakāśa with Nyāyaśikhāmaṇi** — major inaccessible chain
5. **Jayaratha's Tantrālokaviveka** — commentary only (root verses exist)
6. **Kṣemarāja on Netratantra/Svacchandatantra** — commentaries are the rare prize
7. **Mahānayaprakāśa** — niche Krama, CC0

### Tier B — useful but check alternatives
- Kubjikāmatatantra, Mālinīvijayottaratantra, Tantrasāra
- Tantrasamuccaya, Tattvaprakāśa, Īśānagurudevapaddhati, Mañjuśrīmūlakalpa
- Target missing commentaries, not root texts

### Tier C — manuscript projects
- Gadādhara fragments, Pratyaṅgirā/Kubjikā manuscripts
- eGangotri Tantra manuscripts, unpublished paddhatis
- Requires handwriting-aware OCR, page-by-page verification

## 6. Technical notes

### Don't trust Archive OCR blindly
Archive's `_djvu.txt`, `_hocr.html`, EPUB, "PDF WITH TEXT" come from automatic Tesseract. They commonly corrupt: conjunct consonants, anusvāra/visarga, vowel length, danda boundaries, avagraha, commentary markers, interleaved root text/gloss.

### Download order for scholarly extraction
1. Original PDF → 2. JP2 page-image ZIP → 3. Scandata/XML → 4. HOCR → 5. DjVu text (draft only)

HOCR preserves bounding boxes → allows aligning corrected SK with original page.

### Efficient download pattern
Metadata JSON: `https://archive.org/metadata/ITEM_IDENTIFIER`
Direct file: `https://archive.org/download/ITEM_IDENTIFIER/FILENAME`

### Bulk search API
```
https://archive.org/advancedsearch.php?q=language%3ASanskrit+AND+%28tantra+OR+agama+OR+nyaya%29&fl[]=identifier&fl[]=title&fl[]=creator&fl[]=date&rows=500&page=1&output=json
```
