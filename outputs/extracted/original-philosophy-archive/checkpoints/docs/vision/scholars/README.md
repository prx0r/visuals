*2026-08-12. The vision docs about **people**: how scholars are involved, what their new role is, and
how their participation sustains the whole system. This folder indexes (assigns, does NOT rewrite) the
existing docs that live under this lens. Each entry keeps its canonical original — this is a loose
assignment + the relationships between them.*

---

## WHY THIS LENS MATTERS

Pāṭala is not "AI replaces scholarship." It is **AI as the scholarly intelligence layer under human
judgment.** The deepest claim across these docs: the scarce asset is **expert judgment**, not data or
code. Scholars are not a target audience to serve — they are the **contributors whose corrections become
the data capital** the whole system compounds.

The flywheel (from `docs/endgame4.md`):
```
open tools → scholars use them → produce corrections/alignments/senses/parallels
   → Pāṭala becomes better → better tools → more scholars → more unique expert data
```

## HOW THIS LAYER RELATES TO THE OTHERS (the interdependencies)

```
ECONOMICS (the sustainability)  ←  pays scholars, gets data capital
    ↕
SCHOLARS (the human layer)      ←  the contributors whose judgment is the moat
    ↕
FUNCTIONALITY (the tools)       ←  the workbench + skills the scholars use
    ↕
THE SCHOLARLY CORE (the truth)  ←  what every claim resolves to (Layer 2–3 of CORE-BIBLE)
```

**The loop:** functionality gives scholars the tools → scholars produce corrections → economics turns
that into revenue + fellowship funding → more scholars + better functionality → the scholarly core grows
more trustworthy. Scholars are the **spoke that connects the tool layer to the value layer.**

## THE ONE-SENTENCE CARRY-FORWARD

**Scholars are not Pāṭala's audience — they are its engine: their expert judgment and corrections are the
scarce asset the whole system compounds, and their role shifts from document-producer (essay as output)
to structured inquirer in the research graph (essay as one rendering), funded and given tools because
their corrections become the data capital that makes the tools better — closing the flywheel that
sustains the economics, the functionality, and the scholarly core alike.**
