# ECONOMICS — the sustainability layer of the vision

*2026-08-12. The vision docs about **how Pāṭala is sustained**: the scarce assets, the funding channels,
the flywheel, the business model. This folder indexes (assigns, does NOT rewrite) the existing docs
under this lens. The core thesis across all of them: the scarce asset is **expert judgment + provenance +
trusted access**, not data or code.*

---

## WHY THIS LENS MATTERS

The economic thesis is **not "we raise money to translate obscure texts."** It's: Pāṭala builds the
institutional coherence the tantric field lacks, sits on genuinely scarce assets (unique source data +
rights + provenance + expert judgment + relationships + human corrections), and converts scholar
participation into data capital and revenue. The economics is what sustains the whole system — it pays
the scholars whose corrections are the moat.

---

## THE SCARCE ASSETS (the economic thesis)

From `docs/endgame4.md` §0 — what's actually scarce five years out:

```
unique source data      manuscript imaging + transcription + alignment datasets
rights                  legitimate digitisation + AI-data access
provenance              claim → translation → Sanskrit → manuscript witness
expert judgment         the thing no one can clone
trusted relationships   the scholar + institutional network
human corrections       continuously generated supervisory data
```

**The moat stack (weakest → strongest):**
```
weak:  website UI, basic translations
medium: normalized Sanskrit corpus, metadata/bibliography graph
strong: validated cross-text relationships, human-reviewed aligned translations
very strong: historical terminology + expert annotations, scholar reputation network, institutional access
extremely strong: unique manuscript datasets with legitimate rights, years of scholar-correction data, brand trust
```

## THE FLYWHEEL (the core economic engine)

From `docs/endgame4.md` §core flywheel — much stronger than a translation flywheel:

```
OPEN TANTRAKOŚA → best free research tools → SCHOLARS → contribute expertise
   → UNIQUE HIGH-QUALITY DATA
        ↙                    ↘
   AI DATA/API            CONSUMER CONTENT
   (enterprise $)         (courses/apps/retreats)
        ↘                    ↙
             REVENUE
                ↓
          PAY SCHOLARS
                ↓
     digitize / research / film
                ↓
        MORE UNIQUE MATERIAL → TANTRAKOŚA
```

**Translations still happen — but as a byproduct of scholarship and data creation, not the product.**

## HOW THIS LAYER RELATES TO THE OTHERS (the interdependencies)

```
FUNCTIONALITY (the tools)      ←  the workbench that produces the data
    ↕
SCHOLARS (the human layer)     ←  the judgment whose corrections are the data capital
    ↕
ECONOMICS (the sustainability) ←  converts that into revenue + fellowships + digitisation
    ↕
THE SCHOLARLY CORE (the truth) ←  grows more trustworthy → more tools → more scholars → more data
```

**The loop closes:** functionality → scholars produce data → economics monetizes it (AI feed + consumer)
→ pays scholars + funds digitisation → more unique material → stronger scholarly core → better tools.
The economics is the **fuel**; scholars are the **engine**; functionality is the **machine**; the
scholarly core is the **product**.

## THE ONE-SENTENCE CARRY-FORWARD

**Pāṭala's economics is built on genuinely scarce assets — expert judgment, provenance, rights, and
scholar-correction data — not on translating texts: open tools draw scholars whose expertise becomes the
data capital, the flywheel converts that into AI-feed and consumer revenue, revenue pays the scholars and
funds digitisation, and the loop compounds a more trustworthy scholarly core across at least six capital
channels (Gyan Bharatam, IKS, Sanskrit University, ICPR, preservation/UNESCO, NEH, philanthropic, and
commercial AI) — with translations becoming a byproduct, not the product.**
