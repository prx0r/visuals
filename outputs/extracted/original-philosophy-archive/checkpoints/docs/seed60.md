# I. ŚAIVA SIDDHĀNTA — 10 texts

Śaiva Siddhānta is unusually well served by critical Sanskrit editions and French scholarship through IFP/EFEO, while complete English coverage is uneven. The IFP bibliography is an excellent backbone for this school. ([OpenEdition Books][1])

## 1. Parākhyatantra

**Status: ✓ COMPLETE ENGLISH.**

Dominic Goodall's edition is the gold-standard record: critical Sanskrit + annotated English translation. Only the surviving doctrine/yoga material is represented because the unique manuscript itself lacks other sections. ([French Institute of Pondicherry][2])

**Translation / edition**

```text
https://www.ifpindia.org/bookstore/ci98/
```

**Useful classification**

```text
EN complete: yes, for surviving text
Sanskrit critical: yes
Peer-reviewed/scholarly: yes
```

---

## 2. Mṛgendrāgama / Mṛgendratantra

**Status: ◐ ENGLISH PARTIAL; major French translations cover the corpus.**

An early English translation covers the first eleven chapters of the Vidyāpāda. Michel Hulin translated the Vidyā/Yoga portions into French; Hélène Brunner and collaborators translated the Kriyā/Caryā material into French. The IFP edition notes this history explicitly. ([OpenEdition Books][3])

Himalayan Academy also provides an English rendering of the knowledge material by S. P. Sabharathnam. ([Kauai's Hindu Monastery][4])

**Open French edition**

```text
https://books.openedition.org/ifp/1938
```

**Earlier sections / bibliography**

```text
https://books.openedition.org/ifp/10484
```

**Machine-readable Sanskrit**

```text
https://gretil.sub.uni-goettingen.de/gretil.html
```

GRETIL explicitly contains Mṛgendra material including Nārāyaṇakaṇṭha's commentary. ([GRETL][5])

**English web translation**

```text
https://www.himalayanacademy.com/saivite-scriptures/
```

```text
EN complete: no single complete scholarly EN located
EN partial: yes
FR substantial/complete across sections: yes
Sanskrit digital: yes
```

# What the 70-text seed now looks like

We have the previous **10 Trika records** plus these **60 school records**.

But the audit has already shown why the database cannot just have:

```json
"translated": true
```

The actual statuses we need are closer to:

```json
{
  "english": {
    "complete": false,
    "partial": true,
    "coverage": [
      "chapters 1-8"
    ]
  },

  "other_languages": [
    {
      "language": "fr",
      "coverage": "complete"
    }
  ],

  "working_translations": [],

  "sanskrit": {
    "critical_edition": true,
    "etext": true,
    "manuscript": true
  }
}
```

The audit surfaced several especially important corrections:

* **Ajitāgama** → complete five-volume English edition exists. ([IGNCA][8])
* **Kāmikāgama** → large English translation corpus is freely available through Himalayan Academy. ([Kauai's Hindu Monastery][9])
* **Pauṣkarāgama Vidyāpāda** → complete free English translation exists. ([Kauai's Hindu Monastery][10])
* **Sarvajñānottara Vidyā/Yoga** → free English translation exists. ([Kauai's Hindu Monastery][11])
* **Kulārṇavatantra** → at least two complete English editions plus M. P. Pandit's partial/free rendering. ([Motilal Banarsidass][22])
* **Śivadṛṣṭi** → Nemec provides a substantial critical edition/translation, but not the complete work. ([Google Books][48])
* **Netratantra** → chapters 1–8 only; the Routledge volume is scheduled for **November 11, 2026**. ([Routledge][47])
* **Niśvāsa** → several major books are already critically translated, but the large **Guhyasūtra** is a different unresolved target. ([École française d'Extrême-Orient][19])
* **Manthānabhairava** → the **Kumārikākhaṇḍa** is completely translated, but that is only one division of the much larger Tantra. ([Open Library][49])
* **Utpaladeva's Vivṛti** → don't call it “untranslated book”; much of the original is lost, while the recovered fragment is being critically translated article by article. ([Iris][41])

That is already a substantially stronger foundation than the usual Tantra bibliographies online.

The next useful move is to put these **70 records into actual structured JSON/YAML** with normalized fields for `works`, `translations`, `editions`, `resources`, `coverage`, `rights`, and `status_checked`. Then the research we've done stops being trapped in chat and becomes the first ingestible dataset for the site/API.
