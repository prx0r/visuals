Yes. I found **20 additional works/layers worth adding before or alongside your current Śaiva queue**. I’m prioritizing texts that actually help reconstruct the transition from the Vedic religious world into recognizably Śaiva theology, not merely “20 more ancient Sanskrit works.”

One correction from the previous pass: for several Vedic texts, **a Sanskrit edition exists but no complete reliable English translation does**. Those are especially interesting for Pāṭala because they become real translation targets rather than redundant translations.

## What these 20 actually add

Combined with the first batch, your historical corpus is beginning to look properly continuous:

```text
ṚGVEDA
│
├─ Taittirīya / Maitrāyaṇī / Kāṭhaka / Kapiṣṭhala
│       ↓
│   competing Yajurvedic Rudra traditions
│
├─ Atharvaveda
│
├─ Aitareya / Kauṣītaki
│   Taittirīya / Śatapatha
│   Gopatha
│   Pañcaviṃśa / Jaiminīya
│       ↓
│   BRĀHMAṆA transformation
│
├─ Āraṇyakas
│       ↓
│   interiorisation / self / prāṇa
│
├─ Kaṭha
├─ Maitrī
├─ Śvetāśvatara
├─ Mahānārāyaṇa
├─ Atharvaśiras                ★
├─ Kaivalya                    ★
├─ Śiva Upaniṣad
│
├─ Mahābhārata Śiva strata
│
├─ Vāyu
├─ early Skandapurāṇa
├─ Kūrma
├─ Liṅga
│
├─ Pāśupata
├─ Śivadharma
│
└─ Niśvāsa
      ↓
   Mantramārga
      ↓
   YOUR EXISTING TANTRIC QUEUE
```

The **three highest-value additions from this second batch**, for the question “how does Rudra actually become the supreme Śiva?” are probably:

**Atharvaśiras → Kaivalya → Vāyu/Kūrma Purāṇic layer.**

And for the much earlier history, the key addition is not another philosophical Upaniṣad—it is having **Maitrāyaṇī + Kāṭhaka + Kapiṣṭhala + Taittirīya side-by-side**, because then you can actually distinguish *shared Vedic Rudra inheritance* from *recension-specific innovation*.

That is exactly where Pāṭala could eventually start discovering things instead of simply summarizing the standard history.
