# PĀṬALA CONSTITUTION — Agent Carry-Forward

## Definition
Pāṭala is a scholarly intelligence infrastructure whose technical kernel is a provenance-bearing epistemic dependency graph.

## Native objects
Identity → SourceAssertion → TranslationDecision → Proposition → Commitment → Inference → Argument → DebateFrame/SemanticAlignment → Crux → ReviewEvent → ObjectVersion → DerivedState → ImpactReport.

## Never conflate
- code exists vs capability works
- source integrity vs semantic correctness
- corroborated vs accepted
- machine proposal vs human judgment
- reviewer acceptance vs truth
- confidence vs review status
- publication status vs epistemic status

## Core invariants
1. Every canonical ref resolves.
2. Every higher object points downward.
3. Interpretation never silently becomes source.
4. Speaker/commitment is explicit.
5. Uncertainty propagates.
6. Review is append-only; correction supersedes, never erases.
7. Machine may propose; machine may not self-promote.
8. Contradiction requires semantic commensurability.
9. Benchmarks sit outside the production graph.
10. External standards adapt outward; they never dictate Pāṭala's epistemic ontology.
11. Supporting infra stops when adequate for its consumer.
12. False certainty is a severe failure.
13. Abstention is a valid success mode.
14. Every result has lineage.
15. No product claims more than its evaluation proves.

## Build/reuse rule
Own warranted scholarly authority and dependency semantics.
Reuse generic execution, parsing, identity, annotation, publication, search and eval infrastructure.

## Product sequence
Factory → Benchmark → Audit → Review → Workbench.
Consumer/media surfaces are downstream projections.

## Killer flywheel
machine proposal → expert correction → structured ReviewEvent → dependency propagation → benchmark/gold → improved machine → lower review burden → harder scholarship becomes feasible.
